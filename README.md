# יוון 2026 — אתר הטיול המשפחתי 🇬🇷

אתר נלווה לטיול משפחת קלמפרט ביוון (27.7–6.8.2026).
הנתונים נמשכים אוטומטית מגיליון התכנון בגוגל דרייב — כל עדכון בטבלה מופיע באתר ברענון הבא.

- **היום** — הלו"ז של היום + ניווט ב-Waze/Google Maps
- **מסלול** — כל ימי הטיול
- **מידע** — טיסות, רכב שכור, חב"ד, מספרי חירום
- **שבת** — זמני שבת וכשרות בסלוניקי
- **אריזה** — צ'קליסט משפחתי (נשמר בכל מכשיר בנפרד)

עובד גם ללא קליטה — נשמר עותק מקומי במכשיר.
